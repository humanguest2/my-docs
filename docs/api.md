# API 参考

以下接口仅用于文档展示，不提供真实服务。

## 查询文档列表

- 请求方法：GET
- 请求路径：/api/docs
- 功能：返回文档条目列表。

### 返回示例

```json
{
  "items": [
    {"id": 1, "title": "使用指南"}
  ]
}
```

## 查询单篇文档

- 请求方法：GET
- 请求路径：/api/docs/{id}
- 功能：按编号返回一篇文档的正文。

### 参数说明

| 参数 | 位置 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- | --- |
| id | 路径 | 整数 | 是 | 文档编号，从 1 开始 |
| format | 查询 | 字符串 | 否 | `md` 或 `html`，默认 `md` |

### 请求示例

```bash
curl -s "https://example.com/api/docs/1?format=md"
```

## 说明

这一页的接口是**虚构的**，只是用来练习怎样把接口描述写清楚：一个接口至少要说明做什么、从哪里请求、参数是什么、返回什么。本次实践的目标是文档网站本身，不涉及后端开发。
